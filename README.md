🤖 **Enchant** → Get AI-powered precise answers
📄 **Smelt** → Upload docs, AI learns from them
📚 **Loot Table** → Every answer comes with cited sources

```

## ⚙️ How to Spawn — Getting Started

```
  ┌───────────┐
  │   📖      │
  │ SURVIVAL  │
  │  GUIDE    │
  │           │
  └───────────┘
```

</div>

<br/>

### 🪨 Step 1 — Punch the Tree (Clone the Repo)

```bash
git clone https://github.com/poonamlodwal/GovSchemesHub.git
cd GovSchemesHub
```

### ⛏️ Step 2 — Mine the Backend (Backend Setup)

```bash
cd Backend/KIBO
pip install -r requirements.txt

# 🔑 Create .env file with your Enchanted Key
echo "Gov_API_KEY=your_gemini_api_key_here" > .env

# 🚀 Ignite the Nether Portal
cd ../api_integration
python app.py
# ✅ Backend portal opens at http://localhost:5000
```

### 🎨 Step 3 — Build Your House (Frontend Setup)

```bash
cd frontend
npm install
npm run dev
# ✅ Frontend spawns at http://localhost:5173
```

## 🧠 Redstone Wiring — How the RAG Pipeline Works

</div>

```
              ┌───────────────────────────────┐
              │  📝 Player Types a Question    │
              │  "PM-KISAN eligibility?"       │
              └───────────────┬───────────────┘
                              │ ⬇️
              ┌───────────────▼───────────────┐
              │  🔢 Enchanting Table            │
              │  (Gemini embedding-001)         │
              │  Converts question → vectors    │
              └───────────────┬───────────────┘
                              │ ⬇️
              ┌───────────────▼───────────────┐
              │  🗃️  Ender Chest Search          │
              │  (ChromaDB Vector Store)        │
              │  Finds Top-5 matching chunks    │
              └───────────────┬───────────────┘
                              │ ⬇️
              ┌───────────────▼───────────────┐
              │  🤖 Iron Golem Responds          │
              │  (Gemini LLM Flash 3.5)         │
              │  Context + Question → Answer    │
              └───────────────┬───────────────┘
                              │ ⬇️
              ┌───────────────▼───────────────┐
              │  ✅ Loot Drop!                   │
              │  Streamed Answer + [Source N]    │
              │  citations via SSE              │
              └───────────────────────────────┘
```

**The Crafting Steps:**

| Step | Minecraft Equivalent | What Happens |
|------|---------------------|--------------|
| 1️⃣ | 📁 Opening a Chest | Documents uploaded → extracted (PDF/DOCX/CSV) |
| 2️⃣ | ✂️ Stonecutter | Text split into overlapping chunks |
| 3️⃣ | 🔢 Enchanting | Each chunk embedded → stored in ChromaDB |
| 4️⃣ | ❓ Player Question | User asks → query is embedded and searched |
| 5️⃣ | 📋 Loot Table | Top-5 relevant chunks → sent as context to Gemini |
| 6️⃣ | 🤖 Iron Golem | Gemini generates answer with `[Source N]` citations |
| 7️⃣ | ⚡ Lightning Strike | Response streamed token-by-token via SSE |

## 🚀 Deploying to The End — Deployment

</div>

```
┌──────────────────────────────────────────────────┐
│          🌐 D E P L O Y M E N T                  │
│               M A P                               │
├──────────────────────────────────────────────────┤
│                                                  │
│  🟦 Overworld (Frontend)  →  Netlify             │
│     Set VITE_API_BASE env var                    │
│                                                  │
│  🟪 The Nether (Backend)  →  Render              │
│     Set Gov_API_KEY env var                      │
│                                                  │
│  🟨 The End (Live App)    →  schemehub-a.netlify │
│                                                  │
└──────────────────────────────────────────────────┘
```

> [!IMPORTANT]
> **🏗️ Building the Nether Portal to Production:**
> Frontend mein `.env.production` file mein apna live backend URL daalo:
> ```
> VITE_API_BASE=https://your-backend.onrender.com
> ```
> Phir `npm run build` karo aur `dist/` folder deploy karo — portal is ready! 🟣
